# Repository AI Guidance

## Purpose

This repository contains reusable AI workflows, agents, templates, and examples.

## Before changing files

1. Read `README.md`.
2. Identify the relevant category.
3. Inspect the smallest relevant set of files.
4. Preserve existing conventions.
5. Update documentation when structure changes.

## Content rules

- Do not fabricate sources or implementation details.
- Separate facts from assumptions.
- Preserve uncertainty.
- Avoid unnecessary rewrites.
- Keep workflows focused.
- Validate code examples.
- Never include secrets or private information.

## Preferred workflow

Understand → Inspect → Plan → Change → Validate → Summarize

## Output discipline

When proposing a change, explain:

- What changed
- Why it changed
- What was validated
- What remains uncertain
