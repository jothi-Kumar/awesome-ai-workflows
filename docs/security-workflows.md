# Security workflows

Security workflows are intentionally defensive. They help contributors identify and remediate risks; they do not provide instructions for exploiting systems.

Recommended sequence:
1. Define assets and trust boundaries.
2. Identify plausible threats.
3. Validate findings with evidence.
4. Prioritize remediation by impact and exploitability.
5. Re-test after fixes.

See `workflows/security/` for reusable prompts.
