# Dataset Profiling

## Goal

Understand a dataset before analysis.

## Instructions

1. Identify row and column counts.
2. Inspect data types.
3. Measure missingness.
4. Check duplicate records.
5. Inspect categorical cardinality.
6. Check numerical ranges and distributions.
7. Identify suspicious values.
8. Document assumptions.
9. Recommend cleaning only when justified.

## Expected output

- Dataset shape
- Schema
- Missingness
- Duplicates
- Range/distribution observations
- Potential quality issues
- Recommended next steps

## Validation

Never silently drop records or columns.
