# Anomaly Investigation

## Goal

Investigate unusual observations without assuming they are errors.

## Procedure

1. Define the anomaly.
2. Confirm it exists.
3. Check data collection and transformation steps.
4. Compare against relevant peer observations.
5. Check temporal/spatial/contextual patterns.
6. Form hypotheses.
7. Test hypotheses.
8. Classify the result as likely valid, likely erroneous, or unresolved.

## Important

An outlier is not automatically bad data.
